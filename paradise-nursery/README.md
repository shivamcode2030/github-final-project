# Paradise Nursery Shopping Application

Paradise Nursery is a React and Redux shopping cart application for an online houseplant store.

## Included Features

- Landing page with company information and a Get Started button
- Three categories with six unique plants in every category
- Plant thumbnail, name, price, and description
- Add to Cart buttons that become disabled after adding
- Dynamic shopping cart count in the header
- Home, Plants, and Cart navigation
- Redux state management with addItem, removeItem, and updateQuantity reducers
- Increase, decrease, and delete controls on the cart page
- Total plant count, item totals, and cart total
- Checkout button with a Coming Soon message
- Continue Shopping button
- GitHub Pages deployment workflow

## Run locally

npm install
npm run dev

## Production build

npm run build
