# Simple Interest Calculator

## Project Name

Simple Interest Calculator

## Project Details

This project is a Bash-based Simple Interest Calculator. It asks the user to enter the principal amount, rate of interest, and time period, then calculates and displays the simple interest.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## How to Use

Run the `simple-interest.sh` script in a Bash terminal. Enter the principal amount, rate of interest per year, and time period in years when prompted. The calculated simple interest is then displayed.
